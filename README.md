# Rosario Fashion — Shopify Theme

Tema a la medida para **Rosario Fashion** (moda femenina), basado en Dawn de Shopify.

## Identidad (propuesta visual v1)
- Colores: vino #6B1E34, rosa pastel #F6DDE2, crema #FFF9F7, tinta #2A1A20, blush #FBEEF0, champán #B8956A (solo detalles)
- Tipografías: Bodoni Moda (títulos), Cormorant Garamond itálica (nombres de producto), Jost (texto)
- Estilos: `assets/rosario.css`

## Secciones propias (`sections/rf-*.liquid`)
| Sección | Uso |
| --- | --- |
| RF Hero | Foto de campaña con titular y 2 botones |
| RF Category bar | Barra de categorías bajo el header (enlaces definidos en el tema) |
| RF Shop by occasion | Mosaicos de colecciones |
| RF Product grid | Cuadrícula de borde a borde con filtros (tarjeta `snippets/rf-card.liquid`) |
| RF Editorial band | Bloque vino imagen · texto · imagen |
| RF Feature split | Texto + 2 imágenes |
| RF Benefits | Envío, devoluciones, pago, tallas |
| RF Social grid | Fotos de clientas / redes |
| RF Newsletter | Registro al newsletter |

Los textos entre corchetes ([$XX], [X]%) son datos pendientes de definir.
